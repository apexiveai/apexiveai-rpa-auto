# ApexiveAI Enterprise RPA Platform

Initial source scaffold for a group-wide RPA control plane covering MAX Energy, MAX Myanmar Construction, Finance & Accounting, MAX Logistics, and Group-wide workflows.

The current deliverable is a development starter. It is not yet production-secure and does not connect to MAX MYANMAR systems or execute real business actions. See `backend/README.md` for setup and required production hardening.
